# Study Manager 2.0 📚

Python으로 제작한 개인 학습 기록 관리 프로그램입니다. 공부 기록을 저장하고 과목별·기간별 학습량을 확인할 수 있습니다.

## 주요 기능

- 공부 기록 추가, 조회, 수정, 삭제
- 공부 날짜 자동 저장 및 수정
- 과목명·날짜·메모를 이용한 기록 검색
- 총 공부 시간 및 과목별 공부 시간 통계
- 이번 주·이번 달 학습 통계
- 하루 공부 목표 설정 및 달성 현황 확인
- 연속 학습일 및 누적 학습일 계산
- 공부 기록 CSV 파일 내보내기
- JSON 파일을 이용한 데이터 영구 저장
- 잘못된 입력값 검사

## 개발 환경

- Python 3
- Python 표준 라이브러리: json, csv, datetime, os

별도의 외부 패키지를 설치할 필요가 없습니다.

## 실행 방법

저장소를 내려받은 뒤 프로젝트 폴더에서 실행합니다.

\`\`\`bash
python main.py
\`\`\`

## 데이터 파일

프로그램 실행 후 아래 파일이 자동 생성됩니다.

- \`study_data.json\`: 공부 기록
- \`study_settings.json\`: 하루 공부 목표 설정
- \`study_records_날짜.csv\`: CSV 내보내기 결과

기존 버전에서 사용하던 \`study_data.json\`을 그대로 이어서 사용할 수 있습니다.

Python의 함수, 조건문, 반복문, 예외 처리, 파일 입출력과 데이터 처리를 활용해 개인 학습 기록을 관리하는 프로그램입니다. 기존 기록 관리 기능에서 검색·통계·목표 관리·데이터 내보내기 기능으로 확장했습니다.
