
# Study Manager 📚

Python으로 제작한 개인 학습 기록 관리 프로그램입니다.

## 주요 기능

- 공부 기록 추가 및 조회
- 공부 날짜 자동 저장
- 총 공부 시간 확인
- 과목별 공부 시간 통계
- 공부 기록 삭제
- JSON 파일을 이용한 데이터 저장
- 잘못된 입력값 검사

## 개발 환경

- Python 3
- JSON

## 실행 방법

```bash
python main.py
```

## 프로젝트 목적

Python 기초 문법을 활용하여 개인의 학습 기록을 관리하고,
파일 입출력과 데이터 처리 기능을 구현했습니다.
