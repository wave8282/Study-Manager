# Study Manager 3.0 📚

Python으로 제작한 개인 학습 기록 관리 프로그램입니다. 학습 기록부터 목표 관리, 통계, 데이터 백업까지 관리할 수 있습니다.

## 주요 기능

- 공부 기록 추가, 조회, 수정, 삭제
- 공부 날짜 자동 저장 및 수정
- 과목명·날짜·메모 검색
- 누적 공부 시간 및 과목별 통계
- 주간·월간 학습 통계
- 하루 공부 목표 설정 및 달성 현황
- 연속 학습일 및 누적 학습일 계산
- CSV 파일 내보내기
- 오늘의 학습 요약
- 과목별 주간 목표 설정 및 달성률 확인
- JSON 데이터 백업 및 백업 복원
- 잘못된 입력과 파일 오류 처리

## 개발 환경

- Python 3
- Python 표준 라이브러리: csv, json, math, os, shutil, datetime

외부 패키지 설치가 필요하지 않습니다.

## 실행 방법

\`\`\`bash
python main.py
\`\`\`

## 데이터 파일

- \`study_data.json\`: 공부 기록
- \`study_settings.json\`: 하루 목표 및 과목별 주간 목표
- \`study_records_날짜.csv\`: CSV 내보내기 파일
- \`backup_날짜_시간_파일명\`: 백업 파일

기존 2.0의 \`study_data.json\`과 \`study_settings.json\`을 그대로 이어서 사용할 수 있습니다.

## 백업 및 복원 주의사항

- 백업 기능은 현재 공부 기록 파일과 설정 파일을 별도 파일로 복사합니다.
- 복원 기능은 선택한 백업 파일로 해당 원본 파일을 교체합니다.
- 복원 전에는 현재 파일을 먼저 백업하는 것을 권장합니다.
- 복원 후에는 프로그램을 재실행해 주세요.

## 프로젝트 목적

Python의 함수, 조건문, 반복문, 예외 처리, 파일 입출력, JSON·CSV 데이터 처리와 운영체제 파일 관리 기능을 활용해 개인 학습 관리 프로그램을 구현했습니다.
